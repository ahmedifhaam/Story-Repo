# Books Directory

Books are organised by subject. Each book receives a folder only when its research-backed skeleton is created.

- `prophets/<book-id>/` — stories about prophets other than the dedicated Prophet Muhammad collection.
- `prophet-muhammad/<book-id>/` — focused books about the life and teachings of Prophet Muhammad ﷺ.
- `companions/<book-id>/` — verified stories about the Companions.
- `everyday-islam/<book-id>/` — values-based learning. If a child character is invented, label the story clearly as fictional and do not invent religious reports or attribute invented words/actions to historical religious figures.

Every book folder should contain `README.md`, `outline.md`, `sources.md`, `progress.md`, and a `sections/` folder once the skeleton is created. Follow `../prompts/WORKFLOW.md`. Do not create a full book in one generation.
